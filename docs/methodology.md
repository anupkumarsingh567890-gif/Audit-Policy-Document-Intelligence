# Methodology

## 1. Data
Text-based PDFs in four categories: internal audit standards, financial management policies, enterprise risk management guidelines, and regulatory compliance guidelines, plus sample audit reports. Public sources: RBI Master Directions, SEBI regulations, World Bank documents, IIA guidance. Three synthetic sample policies (fictional "Northwind Finance Ltd.") are generated by `scripts/make_sample_docs.py` for immediate testing and a reproducible evaluation set.

## 2. Pre-processing choices
| Choice | Value | Reason |
|---|---|---|
| Chunk size | ~1,000 characters | MiniLM truncates input at 256 word-pieces; 1,000 chars ≈ 200–250 tokens, so the whole chunk is embedded |
| Overlap | ~200 characters (whole sentences) | Keeps facts that straddle a boundary retrievable from either chunk |
| Page boundaries | Never crossed | Each citation refers to exactly one page |
| Header/footer removal | Lines on ≥50% of pages (min 3 pages) | Stops boilerplate dominating similarity |
| Minimum chunk | 50 characters | Drops fragments with no retrievable meaning |

All values are configurable in `.env` and should be tuned with `scripts/evaluate.py`.

## 3. Retrieval
Dense retrieval with cosine similarity over normalised MiniLM embeddings in ChromaDB (HNSW index). Default top-k = 5.

## 4. Generation
Gemini receives a system instruction to answer only from the numbered excerpts, cite them inline, avoid outside knowledge, flag disagreements between sources, and state clearly when the answer is not present. Temperature 0.2 for consistent, factual output.

## 5. Evaluation
| What | Metric | Tool |
|---|---|---|
| PDF extraction | Pages, empty pages, scanned-document flag; manual check of `data/processed/` JSON | `pdf_loader`, tests |
| Chunking | Size limits, overlap, sentence boundaries, metadata preserved | `tests/test_chunker.py` |
| Embeddings | Related text more similar than unrelated text | `tests/test_embeddings.py` |
| Retrieval | Hit@1, Hit@k, MRR against expected (file, page) | `scripts/evaluate.py` |
| Answer quality | Keyword recall of expected facts | `scripts/evaluate.py --rag` |
| Source accuracy | Answers carry `[n]` citations; references match expected page | `scripts/evaluate.py` |
| Hallucination | Abstains on questions the documents cannot answer | `scripts/evaluate.py --rag` (questions 23–24) |

Comparing retrieval-only output with Gemini output for the same questions shows the LLM's contribution: synthesis across passages, plain-language explanation and direct answers, while retrieval-only guarantees verbatim source text.

## 6. Security
API key only in `.env` (git-ignored, loaded via python-dotenv, never hard-coded). Original PDFs are never modified. Processed data and the vector store are kept separate and git-ignored.
